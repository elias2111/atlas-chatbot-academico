Conexión n8n

        

          
Con la URL, cada pregunta va al agente RAG de n8n (PostgreSQL + reglamento + LLM) junto con tu expediente. Vacío = IA directa o motor local.

        

      

      
Base de datos académica

        
Sin configurar, las notas y tareas se guardan en este teléfono. Para conectarla a una base de datos PostgreSQL real, crea un proyecto gratis en Supabase, ejecuta backend/schema.sql y pega aquí la URL y la anon key (Project Settings → API).

        

        

        

        

        

      

      
IA directa (sin n8n)

        

          
Opcional. Con la key, ATLAS responde preguntas abiertas con IA usando tu expediente. Se guarda solo en este teléfono. Si hay webhook de n8n, se usa n8n primero.
