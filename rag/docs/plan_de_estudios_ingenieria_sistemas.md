# Plan de estudios de Ingeniería de Sistemas (UNAB) · 9 semestres, 151 créditos

Fuente: plan de estudios oficial del programa (asignaturas y créditos por semestre). Los prerrequisitos no aparecen en el plan publicado; los que se indican aquí son la propuesta que usa ATLAS y deben confirmarse con la coordinación del programa.

## Rutas críticas del plan

- Cálculo diferencial → Cálculo integral → Cálculo en varias variables y Ecuaciones diferenciales → Dinámica de sistemas. Atrasar Cálculo integral retrasa al menos tres asignaturas.
- Fundamentos de programación → Programación de computadores → Estructura de datos y análisis de algoritmos → Base de datos I → Ingeniería de software I → Ingeniería de software II → Proyectos en ingeniería de sistemas I → Proyectos en ingeniería de sistemas II → Práctica en ingeniería de sistemas (12 créditos).
- Infraestructura tecnológica → Internet de las cosas y Ciberseguridad.
- Álgebra lineal y Estadística general → Investigación de operaciones I → Investigación de operaciones II.

## Electivas

El plan incluye cuatro electivas de profundización (semestres 5 a 8), dos electivas sociohumanísticas (semestres 7 y 8) y dos electivas de contexto (semestres 7 y 9), de 3 créditos cada una. El estudiante elige el curso concreto (por ejemplo Sistemas Inteligentes como electiva de profundización).
